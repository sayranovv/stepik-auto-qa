# Проверка магазина на разных языках

Тест открывает страницу товара в Chrome и проверяет наличие видимой,
уникальной кнопки добавления в корзину. Язык задаётся параметром `--language`
(по умолчанию `en`). Браузер передаётся через фикстуру `browser` и закрывается
после теста, в том числе при ошибке.

## Установка

Нужны Python 3.10+ и установленный Google Chrome.
Selenium Manager автоматически подбирает драйвер; при первом запуске требуется
доступ к интернету для его загрузки.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск

```bash
pytest --language=es test_items.py
pytest --language=es
```

Для визуальной проверки французского интерфейса:

```bash
pytest --language=fr test_items.py
```

Сразу после открытия страницы тест ждёт 30 секунд: за это время можно
проверить, что на кнопке написано **Ajouter au panier**.
Селектор не зависит от текста кнопки и выбранного языка.

Чтобы избежать конфликта регистрации `--language`, запускайте тест из этого
репозитория и убедитесь, что в родительских каталогах нет другого `conftest.py`,
добавляющего такой же параметр.
